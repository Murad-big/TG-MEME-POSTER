# Бот с мемами для Telegram

Бот на Python, который загружает картинки с Memify и отправляет случайный мем по команде. Отправленная картинка удаляется из локальной подборки, а когда подборка заканчивается, бот загружает следующую.

## Команды

- `/start` — приветствие.
- `!мем` — случайная картинка.
- `!кубик` — бросок кубика.

В исходнике также есть `!информация`, но для неё пока не настроена передача времени запуска.

## Запуск

1. Создайте бота через BotFather.
2. Установите зависимости в отдельное виртуальное окружение:

```bash
python -m pip install aiogram pyTelegramBotAPI requests beautifulsoup4 lxml pydantic-settings
```

3. Создайте рядом с `SonMark.py` файл `token.env`:

```dotenv
BOT_TOKEN=вставьте_свой_токен
```

4. Подготовьте локальную подборку и запустите бота:

```bash
python meme-generator.py
python SonMark.py
```

Токен храните только локально.

## Файлы

- `SonMark.py` — команды и отправка картинок.
- `meme-generator.py` — создание папки и загрузка изображений.
- `config_reader.py` — чтение настроек из `token.env`.

Загрузка зависит от доступности и разметки Memify. В этой версии сетевые запросы при пополнении подборки выполняются синхронно, поэтому бот в это время может отвечать с задержкой.
